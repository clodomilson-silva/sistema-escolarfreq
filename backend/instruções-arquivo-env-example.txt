# Instruções para o uso dos arquivos .env.example e .env

1. **Criação do arquivo `.env.example`**:
    - O arquivo `.env.example` deve conter todas as variáveis de ambiente necessárias para o funcionamento do projeto, mas sem os valores sensíveis. 
    - Exemplo de conteúdo do arquivo `.env.example`:
      ```
      DB_NAME=
      DB_USER=
      DB_PASSWORD=
      DB_HOST=localhost
      DB_PORT=5432
      ```

2. **Criação do arquivo `.env`**:
    - O arquivo `.env` deve ser criado a partir do `.env.example` e preenchido com os valores reais das variáveis de ambiente.
    - Exemplo de conteúdo do arquivo `.env`:
      ```
      DB_NAME=nome_do_banco
      DB_USER=usuario
      DB_PASSWORD=senha
      DB_HOST=localhost
      DB_PORT=5432
      ```

3. **Instalação do pacote `python-dotenv`**:
    - Certifique-se de que o pacote `python-dotenv` está instalado no ambiente do projeto.
    - Para instalar, execute o comando:
      ```
      pip install python-dotenv
      ```

4. **Configuração no arquivo `settings.py`**:
    - O arquivo `settings.py` já está configurado para carregar as variáveis de ambiente do arquivo `.env` usando o pacote `python-dotenv`. Certifique-se de que o arquivo `.env` está localizado na raiz do projeto.

5. **Importante**:
    - Nunca adicione o arquivo `.env` ao controle de versão (como Git). Certifique-se de que ele está listado no arquivo `.gitignore`.
    - O arquivo `.env.example` deve ser incluído no controle de versão para que outros desenvolvedores saibam quais variáveis de ambiente são necessárias.
